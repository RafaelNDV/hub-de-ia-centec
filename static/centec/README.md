# Assets oficiais do Instituto Centec

Este diretório contém os arquivos de identidade visual aprovados para a Cora, do Instituto Centec.

- `simbolo-centec.png`: símbolo compacto usado na sidebar aberta e recolhida.
- `logo-centec-horizontal.png`: assinatura horizontal usada no cabeçalho da autenticação.

Os PNGs possuem fundo transparente. O símbolo compacto é exibido sobre a cor azul institucional para manter contraste nos temas claro e escuro. Uma futura versão em SVG pode substituir estes arquivos mantendo os mesmos papéis visuais.

A atribuição ao Open WebUI deve permanecer visível na interface conforme as condições da licença do projeto.
