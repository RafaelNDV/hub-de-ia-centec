# Assets oficiais do Instituto Centec

Este diretório está reservado para a identidade visual oficial do Instituto Centec.

Quando os arquivos forem fornecidos, coloque aqui as versões aprovadas da marca (preferencialmente SVG, incluindo uma versão adequada para fundo escuro, se existir). Até lá, a interface mantém o ícone original do Open WebUI e usa apenas o nome e a paleta institucional, sem inventar ou redesenhar a marca do Centec.
